L3 INTERVIEW CIRCUIT
====================

This folder contains the complete self-contained website.

FILES
-----
index.html   - HTML structure, CSS styling, and interaction logic
problems.js  - The complete 350-problem roadmap data

HOW TO RUN
----------
1. Keep index.html and problems.js in the same folder.
2. Double-click index.html to open it in a modern web browser.
3. No installation, web server, framework, or build command is required.

IMPORTANT
---------
Progress is stored in that browser using localStorage. It does not automatically
sync between computers, browsers, the local copy, and the hosted Site.
